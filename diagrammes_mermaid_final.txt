Voici les diagrammes Mermaid.js complets, stylisés et incluant tous les nouveaux concepts (Signal Agent, Ré-entraînement, MAS, RAG).

--------------------------------------------------
1. ARCHITECTURE GLOBALE DU SYSTÈME (MAS + LANGGRAPH)
Emplacement : Section 1.4.3.2
Description : Illustre la collaboration entre les agents spécialisés et le rôle décisionnel du Signal Agent.
--------------------------------------------------
graph TD
    %% Noeuds principaux
    Start((Début)) --> Coord[Coordinateur LangGraph]
    
    subgraph "Comité d'Experts (Agents)"
        Coord --> Tech[Agent Technique<br/>XGBoost]
        Coord --> Sent[Agent Sentiment<br/>NLP/News]
        Coord --> Vol[Agent Volatilité]
    end

    Tech --> Agg[Signal Agent]
    Sent --> Agg
    Vol --> Agg

    subgraph "Phase de Validation"
        Agg -->|Proposition de Trade| Devil[Avocat du Diable]
        Devil -->|Analyse Critique| Risk[Risk Manager]
    end

    Risk -->|Ordre Validé| Exec[Exécuteur CCXT]
    Risk -->|Rejet| Coord

    %% Styles
    style Coord fill:#f9f,stroke:#333,stroke-width:2px
    style Agg fill:#f9f,stroke:#333,stroke-width:4px
    style Devil fill:#fdd,stroke:#f66,stroke-width:2px
    style Risk fill:#dfd,stroke:#3c3,stroke-width:2px
    style Exec fill:#eee,stroke:#333,stroke-dasharray: 5 5

2. PIPELINE D'APPRENTISSAGE CONTINU (AUTO-RETRAIN)
Emplacement : Section 1.4.3.3
Description : Montre comment le système s'auto-améliore pour éviter l'obsolescence des modèles.
--------------------------------------------------
graph LR
    subgraph "Collecte & Stockage"
        A[Flux Marché Temps Réel] --> B[(Base de Données DB)]
        B --> C{Nouveau Volume de Données?}
    end

    subgraph "Entraînement Automatique"
        C -- Oui --> D[Calcul de Features<br/>TA-Lib]
        D --> E[Entraînement XGBoost]
        E --> F[Validation Performance]
    end

    subgraph "Déploiement"
        F -->|Si Score > Seuil| G[(Model Store)]
        G -.-> H[Agent Technique]
    end

    style E fill:#bbf,stroke:#333,stroke-width:2px
    style G fill:#bbf,stroke:#333,stroke-width:2px
